# metjou-backend

Backend for the MetJou safety app. First feature: the "Wat moet ik doen?"
assistant, which answers safety questions with quotes from official Dutch
sources (Veilig Thuis, Centrum Seksueel Geweld, Slachtofferhulp Nederland,
113 Zelfmoordpreventie, Rijksoverheid), always with a link to the source.

## Setup

    uv sync
    uv run pytest
